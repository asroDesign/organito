# پیاده‌سازی نشست‌های فعال و امنیت حساب

## نتیجه

مورد ۲۱ از مسیر توسعهٔ شکاف‌ها تکمیل شد. کاربر اکنون می‌تواند نشست‌های معتبر حساب را ببیند و دسترسی یک دستگاه دیگر را خاتمه دهد.

## قابلیت‌ها

- صفحه `/customer/security` در منوی حساب مشتری قرار دارد.
- فهرست نشست‌ها شامل مرورگر و پلتفرم تقریبی، زمان ورود، زمان انقضا و IP ناقص‌شده است.
- نشست فعلی با نشان «این دستگاه» مشخص می‌شود و از این صفحه قابل حذف نیست؛ خروج معمول از پنل آن را پایان می‌دهد.
- پایان نشست دیگر با مودال تأیید انجام می‌شود. API فقط نشست متعلق به همان کاربر را حذف می‌کند.
- در ورود با رمز یا کد یک‌بارمصرف، اعلان داخلی برای حساب ثبت می‌شود و به صفحه امنیت حساب پیوند دارد؛ هنگام ثبت‌نام اولیه اعلان ورود تکراری ثبت نمی‌شود.
- هیچ مکان جغرافیایی از IP تخمین زده نمی‌شود. user-agent کامل یا IP کامل در پاسخ API صفحه نمایش داده نمی‌شود.

## داده و سازگاری

از جدول موجود `sessions` استفاده شد که توکن را به صورت hash، و زمان انقضا، IP و user-agent را ذخیره می‌کند. migration جدید لازم نبود و نشست‌های موجود دست‌نخورده باقی ماندند. هر نشست پس از ۷ روز منقضی می‌شود؛ کاربر می‌تواند نشست‌های دیگر را زودتر خاتمه دهد.

## اعتبارسنجی و دمو

- `yarn typecheck` — موفق.
- `git diff --check` — موفق.
- صفحهٔ دمو در Chrome: [http://localhost:3003/customer/security](http://localhost:3003/customer/security).
- نشست آزمایشی ایجاد یا حذف نشد.
