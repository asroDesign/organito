# خوراک فعالیت مدیریتی و گزارش رویدادها

## نتیجه

مرحلهٔ ۲۲ تکمیل شد. صفحهٔ موجود `/admin/audit` اکنون یک خوراک فارسی از رویدادهای ممیزی است و فعالیت‌ها را با فیلتر و صفحه‌بندی برای مدیر دارای مجوز ممیزی نمایش می‌دهد.

## فیلتر و پیمایش

- جستجوی عامل، نام عملیات، نوع مورد یا شناسهٔ رکورد.
- فیلتر گروه عملیات و نوع مورد.
- انتخاب بازه با تقویم شمسی؛ گزارش زمان را بر اساس منطقهٔ زمانی تهران محاسبه می‌کند.
- صفحه‌بندی قابل تنظیم با اندازه‌های ۱۰، ۲۵، ۵۰ و ۱۰۰ ردیف.
- پیوند از رخداد به صفحهٔ محصول، سفارش، تیکت، تأمین، کاربر و سایر بخش‌های شناخته‌شده.

## نمایش داده و دسترسی

- هر ردیف زمان، عامل، نقش، گروه/نوع عملیات، شناسهٔ رخداد و حداکثر سه فیلد خلاصهٔ مجاز را نمایش می‌دهد.
- JSON خام قبل/بعد، IP و user-agent در خوراک دیده نمی‌شوند؛ فیلدهای خلاصه با allowlist انتخاب می‌شوند.
- مجوز موجود `AUDIT_LOG_VIEW` همچنان شرط دسترسی است.
- صفحه از `audit_logs` موجود می‌خواند. schema، داده‌های ذخیره‌شده و جریان ثبت audit تغییر نکردند؛ migration جدید وجود ندارد.
- خوراک فقط رخدادهایی را پوشش می‌دهد که سرویس‌ها ثبت می‌کنند و جایگزین analytics رفتاری رضایت‌محور نیست.

## اعتبارسنجی و دمو

- `tsc --noEmit --incremental false` — موفق.
- `git diff --check` — موفق.
- دمو در Chrome: [http://localhost:3003/admin/audit](http://localhost:3003/admin/audit).
- ۴۶۵ رخداد واقعی دیتابیس توسعه نمایش داده شد؛ داده‌ای برای دمو اضافه یا تغییر داده نشد.
