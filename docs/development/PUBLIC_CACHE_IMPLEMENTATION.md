# گزارش پیاده‌سازی cache عمومی هدفمند

## محدودهٔ cache

از `unstable_cache` نسخهٔ Next.js با عمر پنج دقیقه و tagهای ابطال استفاده می‌شود. داده‌های عمومی زیر cache می‌شوند:

- دادهٔ دسته‌بندی‌های فروشگاه و شمارش محصولات هر دسته.
- فهرست گواهی‌ها و رژیم‌های قابل فیلتر در کاتالوگ.
- فهرست مقاله‌های منتشرشده، دسته‌ها و برچسب‌های وبلاگ، مقالهٔ منتشرشده، مطالب مرتبط و آرشیو هر برچسب.
- صفحه‌های محتوایی منتشرشده، از جمله محتوای صفحهٔ اصلی.
- اطلاعات عمومی برند و شمارش محصولات در فهرست برندها.

## داده‌هایی که cache نمی‌شوند

`listShopProducts` عمداً cache نشده است؛ این query قیمت‌های پایه و فروشنده، تخفیف، موجودی، سفارش‌های فروخته‌شده و امتیاز را ترکیب می‌کند. صفحهٔ جزئیات محصول نیز محصول، تنوع، پیشنهاد فروشنده، موجودی، جشنواره، پرسش‌ها و دیدگاه‌ها را مستقیم می‌خواند. checkout، رزرو انبار، کیف پول، سفارش و پاسخ درگاه پرداخت نیز از این cache استفاده نمی‌کنند.

تنظیمات عمومی نیز cache نشده‌اند، چون همان مخزن شامل تنظیمات محرمانهٔ درگاه و پیامک است. این کار از ورود مقدار محرمانه به cache عمومی جلوگیری می‌کند.

## ابطال پس از تغییر

tagها در `src/lib/public-cache.ts` تعریف شده‌اند. API dispatcher پس از موفقیت هر mutation مرتبط، tag مناسب را با انقضای صفر پاک می‌کند:

- محصول، موجودی، قیمت، تنوع، جشنواره، سفارش و مرجوعی: دسته‌بندی‌های عمومی و برندها.
- مقاله، taxonomy وبلاگ، صفحهٔ محتوایی، صفحه‌ساز و محتوای سایت: وبلاگ و صفحه‌های عمومی.
- ایجاد، ویرایش، بایگانی یا حذف برند: فهرست و صفحه‌های عمومی برند.

Cache TTL پنج‌دقیقه‌ای حد دوم برای ورود دادهٔ برنامه‌ریزی‌شده یا تغییری است که از مسیر مدیریت عبور نکرده باشد. cacheهای صفحهٔ برند و وبلاگ به صورت دادهٔ معرفی/محتوا هستند؛ کارت کالا در صفحه برند همچنان قیمت و موجودی تازه می‌گیرد.

## فایل‌های اصلی

- `src/lib/public-cache.ts`: tagها و توابع ابطال.
- `src/lib/public-content-cache.ts`: cache وبلاگ و صفحه‌های محتوایی.
- `src/lib/public-brand-cache.ts`: cache عمومی برندها.
- `src/lib/queries.ts`: cache دسته‌بندی و گزینه‌های فیلتر، بدون cache کردن لیست قیمت/موجودی کالا.
- `src/lib/api/router.ts`: ابطال مرکزی بعد از mutation موفق.

## بررسی و دمو

`./node_modules/.bin/tsc --noEmit --incremental false` و `git diff --check` موفق شدند. مسیرهای مرور عمومی برای دمو: `/shop`، `/blog`، `/categories`، `/brands` و یک صفحهٔ محتوایی مانند `/pages/about`.
