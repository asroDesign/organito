# صفحه‌ساز صفحات محتوا و الگوهای آماده

## نتیجه

مرحلهٔ ۲۴ گزارش شکاف‌ها برای صفحه‌های محتوایی تکمیل شد. مدیریت صفحات سایت اکنون الگوهای شروع، پیش‌نمایش زندهٔ تغییرات ذخیره‌نشده و تاریخچهٔ بازیابی دارد. بلوک‌های موجود صفحات تا زمانی که مدیر یک الگو را صریحاً انتخاب و ذخیره نکند تغییری نمی‌کنند.

## قابلیت‌ها

- چهار الگوی قابل انتخاب برای معرفی برند ارگانیک، راهنمای پرسش‌های متداول، مقالهٔ تصویری و تماس/پشتیبانی اضافه شد. پس از اعمال، همهٔ بلوک‌ها مثل بلوک‌های عادی صفحه قابل ویرایش، جابه‌جایی و حذف هستند.
- پیش از جایگزینی محتوای پیش‌نویس با الگو تأیید گرفته می‌شود. تغییر وضعیت انتشار نیز همچنان فقط از فرم صفحه انجام می‌شود.
- پیش‌نمایش در پنجرهٔ واکنش‌گرا باز می‌شود و عنوان، خلاصه و بلوک‌های فعلی را بدون ذخیرهٔ صفحه نشان می‌دهد.
- پیش از هر تغییر واقعی صفحه، نسخهٔ قبلی با متن، slug، طرح، بلوک‌ها، اطلاعات SEO و وضعیت ذخیره می‌شود. حداکثر ۲۰ نسخهٔ اخیر برای هر صفحه نگهداری می‌شود.
- بازیابی نسخه، محتوای انتخاب‌شده را در ویرایشگر قرار می‌دهد و وضعیت را به پیش‌نویس تغییر می‌دهد؛ انتشار عمومی خودکار انجام نمی‌شود.
- API نسخه‌ها به مجوز `SETTINGS_MANAGE` محدود است و اعتبارسنجی سروری ساختار بلوک‌ها و پیوندها همچنان برقرار است.

## فایل‌ها و داده

- `src/components/SiteContentManager.tsx`: الگوها، پیش‌نمایش و رابط تاریخچه/بازیابی.
- `src/lib/api/content.ts`: ذخیرهٔ snapshot، فهرست نسخه‌ها و بازیابی نسخه با ثبت رویداد audit.
- `src/db/schema.ts`: مدل `content_page_revisions`.
- `drizzle/0057_content_page_revisions.sql`: migration افزایشی جدول تاریخچه و ایندکس آن.

این migration جدول جدید می‌سازد و هیچ جدول یا داده‌ای را حذف یا بازنویسی نمی‌کند. migration روی دیتابیس محلی `organito` اجرا شد. اجرای عمومی `scripts/migrate.mjs` روی همین دیتابیس با خطای قدیمی `0010_media_library.sql` متوقف شد، چون آن migration ستون حذف‌شدهٔ `media.data` را انتظار دارد؛ اجرای زنجیره روی production انجام نشد. بنابراین migrationهای قدیمی باید در مسیر انتشار بعدی به شکل کنترل‌شده ثبت/رفع شوند و migration `0057` در production فقط پس از تأیید مسیر مهاجرت آن اعمال شود.

## بررسی و دمو

- بررسی TypeScript با `tsc --noEmit` موفق بود.
- `git diff --check` موفق بود.
- آدرس دمو: `http://localhost:3003/admin/site-content`. Chrome به صفحهٔ ورود هدایت شد و نشست ادمین محلی در دسترس نبود؛ پس از ورود مدیر، الگوها در فرم ویرایش صفحه و تاریخچه در صفحات ذخیره‌شده قابل مشاهده است.

## مرحلهٔ بعد

مرحلهٔ ۲۵ گزارش اصلی: پردازش رسانه شامل crop، اندازه‌های مشتق، خروجی WebP/AVIF در صورت پشتیبانی، تنظیم کیفیت و متن جایگزین. فایل اصلی باید حفظ شود و وضعیت خطا/پردازش برای مدیر دیده شود.
