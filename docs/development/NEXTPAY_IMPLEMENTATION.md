# گزارش پیاده‌سازی درگاه نکست‌پی

**تاریخ:** ۶ اکتبر ۲۰۲۶  
**مرجع فنی:** [راهنمای فنی درگاه NextPay](https://nextpay.ir/docs/NextPay-WebService-Technical-Guid-V2.0.pdf)

## تغییرات

- یک تب مستقل «نکست‌پی» به صفحهٔ درگاه‌ها اضافه شد؛ مدیر می‌تواند در آن درگاه را فعال یا غیرفعال کند، کلید API را تنظیم کند و آیکن را از مرکز رسانه انتخاب کند.
- نکست‌پی به گزینه‌های پرداخت قابل انتخاب سبد خرید افزوده شد و از همان تنظیمات فعال‌سازی چند درگاه هم‌زمان استفاده می‌کند.
- هنگام آغاز پرداخت، رکورد پرداخت محلی ابتدا ساخته می‌شود؛ شناسهٔ یکتای آن به‌شکل `NP-{paymentId}` به NextPay ارسال می‌شود تا در callback قابل تطبیق باشد.
- درخواست توکن به `https://api.nextpay.org/gateway/token.http` با HTTPS ارسال می‌شود. مبلغ مطابق راهنمای درگاه به تومان و شناسهٔ سفارش، کلید API و نشانی بازگشت ارسال می‌شوند. فقط کد `-1` همراه شناسهٔ تراکنش به‌عنوان ایجاد موفق پذیرفته می‌شود.
- callback از نوع POST، `order_id` و `trans_id` را می‌خواند و هر دو را با رکورد پرداخت داخلی و شناسهٔ ذخیره‌شده تطبیق می‌دهد. بازگشت مرورگر به‌تنهایی پرداخت را موفق نمی‌کند.
- مبلغ، شناسهٔ سفارش و `trans_id` ذخیره‌شده برای تأیید سروری به `https://api.nextpay.org/gateway/verify.http` ارسال می‌شوند. فقط کد `0` به‌عنوان موفقیت پذیرفته می‌شود؛ پس از آن جریان موجود پرداخت سفارش/پیش‌فاکتور یا شارژ کیف پول را اجرا می‌کند.
- callback تکراری بعد از موفقیت از مسیر idempotent موجود نتیجهٔ موفق قبلی را برمی‌گرداند و دوباره کیف پول یا سفارش را تسویه نمی‌کند.
- در صفحهٔ نتیجه، نام درگاه و کد رهگیری نکست‌پی نمایش داده می‌شود.

## محدودیت و نیازهای راه‌اندازی

- کلید API معتبر پذیرنده باید در پنل مدیریت ثبت شود؛ بدون آن درگاه برای تراکنش واقعی قابل استفاده نیست.
- قرارداد سند NextPay قدیمی است (نسخهٔ ۲٫۰). پیش از بهره‌برداری با حساب پذیرنده، سازگاری endpointها و قالب پاسخ با نسخهٔ فعال حساب بررسی شود. برای محافظت ارتباط، فقط نشانی‌های HTTPS مستندشده استفاده می‌شوند.
- عملیات settle/revert جداگانه در این API پیاده نشده و سند NextPay برای این جریان، تأیید `verify` را مرحلهٔ نهایی معرفی می‌کند.
- این مرحله فقط NextPay را اضافه می‌کند؛ سایر ارائه‌دهندگان بخش درگاه‌های گزارش شکاف در کارهای بعدی باقی می‌مانند.
